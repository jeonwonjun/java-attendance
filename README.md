# java-attendance

출석 미션 저장소

## 입력 요구 사항
프로그램을 시작하면 src/main/resources/attendances.csv를 통해 구현에 필요한 정보 조회
- 닉네임과 출석 일시 기록됨
- 파일의 내용 수정 불가
### 초기 입력
```
오늘은 12월 14일 토요일입니다. 기능을 선택해 주세요.
1. 출석 확인
2. 출석 수정
3. 크루별 출석 기록 확인
4. 제적 위험자 확인
Q. 종료
```

## 기능 요구 사항
### 출석 관리 규칙 및 시스템 설계 정책
- 시간은 24시간 형식
- 교육시간
  - 월요일 13:00 ~ 18:00
  - 화요일 ~ 금요일 10:00 ~ 18:00
1. 출석 기록
  - 출석: 해당 요일 시작 시간 이전
  - 지각: 해당 요일 시작 시간 이후 5분 초과
  - 결석: 해당 요일 시작 시간 이후 30분 초과, 출석 기록 x
2. 출석 관리
  - 경고 대상자: 결석 2회 이상
  - 면담 대상자: 결석 3회 이상
  - 제적 대상자: 결석 5회 초과
    * 지각 3회는 결석 1회
* 캠퍼스 운영 시간(08:00~23:00)
* 주말 및 공휴일은 출석 x
* 프로그램은 사용자가 종료할 때까지 진행, 해당 기능을 수행한 후 ```초기 화면으로 이동```
  - 사용자가 잘못된 값을 입력한 경우 "[ERROR]"로 시작하는 메시지와 함께 IllegalArgumentException을 발생시킨 후 ```애플리케이션 종료```되어야 한다.

### 출석 확인
1. 입력
  - 닉네임 입력
  - 등교 시간 입력(09:59 형식)
2. 출력
  - 출석 기록 확인
    - 예시: ```12월 05일 09:59 (출석)```
3. 예외
   - 시간 입력 형식이 안맞을 경우
   - 출석부에 없는 이름일 경우
   - 이미 출석부에 이름이 있을 경우 **출석 수정** 기능 안내
   - 캠퍼스 운영시간이 아닐 경우

### 출석 수정
1. 입력
  - 닉네임 입력
  - 수정하려는 일 입력
  - 변경 시간 입력
2. 출력
  - 수정 전, 후 비교 출력
    - 예시: ```12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!```
3. 예외
  - 입력 형식이 안맞을 경우
  - 출석부에 이름이 없을 경우
  - 미래 날짜를 수정할 경우

### 출석부 조회
1. 입력
  - 닉네임 입력
2. 출력
  - 이번 달 출석 기록 출력
  - 이번 달 출석 기록 통계 출력
  - 이번 달 어떤 대상자인지 출력

### 제적 위험자 확인
1. 기능
   - 전날까지의 출석 기록 조회
   - 출석 기록을 바탕으로 횟수 정리
   - 제적, 면담, 경고 대상자순으로 출력
     - 지각을 결석으로 간주하여 내림차순
     - 출석 상태가 같으면 닉네임으로 오름차순
