# java-attendance

출석 미션 저장소

## 기능 요구 사항

- 시간은 24시간 형태. 예: "22:30" 형식
- 교육 시간은 월요일 13:00~18:00, 화-금요일 10:00~18:00
  - 교육 시간 5분 초과 = 지각
  - 교육 시간 30분 초과 = 결석
  - 출석 기록 없는 날 = 결석
- 캠퍼스 운영시간 매일 08:00~23:00(주말 및 공휴일 제외)
- 사용자 종료할 때까지 트래잭션 반복, 오류 시 종료

### 1. 입력
- [ ] 파일 입출력
- [ ] 출석 확인(1)
  - 닉네임, 등교 시간 차례로 입력
    - [예외] 주말 또는 공휴일인 경우
    - [예외] 닉네임이 출석부에 있는 경우
    - [예외] 입력 형식이 맞지 않는 경우
    - [예외] 캠퍼스 운영 시간이 아닌 경우
    - [예외] 이미 출석을 했는데 다시 출석 확인을 하는 경우
- [ ] 출석 수정(2)
  - 닉네임, 날짜(일), 변경 시간 차례로 입력
    - [예외] 닉네임이 출석부에 없는 경우
    - [예외] 입력 형식이 맞지 않는 경우
    - [예외] 캠퍼스 운영 시간이 아닌 경우
    - [예외] 미래 날짜로 출석을 수정하는 경우
- [ ] 크루별 출석 기록 확인(3)
  - 닉네임 입력
    - [예외] 닉네임이 출석부에 없는 경우
    - [예외] 입력 형식이 맞지 않는 경우
- [ ] 제적 위험자 확인(4)
- [ ] 종료(Q)

### 2. 출력
- [ ] 출석 확인(1)
  - 출석 후 출석 기록 출력: ```12월 05일 화요일 09:59 (출석)```
- [ ] 출석 수정(2)
  - 수정 후 변경 기록 출력: ```12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!```
- [ ] 출석 기록 확인(3)
  - 저장된 출석 기록 출력
  - 출석, 지각, 결석에 대한 횟수 출력
  - 경고, 면담, 제적 대상자면 해당 내용 출력
- [ ] 제적 위험자 확인(4)
  - 제적, 면담, 경고 대상자 순으로 출력
  - 지각을 결석으로 간주하여 내림차순, 출석 상태가 같으면 닉네임으로 오름차순
     
### 3. 핵심 로직
- [ ] 출석 확인
  1) 닉네임 입력 및 검증
  2) 데이터베이스 내에 닉네임 비교
  3) 데이터베이스에 닉네임 없으면 시간 입력
  4) 시간 검증
  5) 형식, 운영시간 이상 없으면 데이터베이스에 기록
  6) 인원별 출석, 지각, 결석 횟수도 기록
- [ ] 출석 수정
  1) 닉네임 입력 및 검증
  2) 데이터베이스 내에 닉네임 비교
  3) 데이터베이스에 닉네임 있으면 수정할 일자 입력
  4) 수정할 일자 검증
  5) 미래 날짜가 아니라면 시간 입력
  6) 운영 시간 이내라면 데이터베이스 수정
- [ ] 크루별 출석 기록 확인
  1) 닉네임 입력 및 검증
  2) 데이터베이스 내에 닉네임 비교
  3) 데이터베이스에 저장된 기록 출력
  4) 출석횟수기록으로 대상자 검증
  5) 대상자라면 출력
- [ ] 제적 위험자 확인
  1) 출석횟수로 제적, 면담, 경고 계산
  2) 지각 3회 = 결석 1회 / 제적: 결석 5회 초과 / 면담: 결석 3회 이상 / 경고: 결석 2회 이상
  3) 계산 결과 데이터베이스에 기록
  4) 기록 중 결석이 높은 순으로 내림차순, 닉네임으로 오름차순 정렬
